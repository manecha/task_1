# 今日やること

その日にやることだけを、素早く確認・記録するための個人用タスク管理アプリです。

公開URL: https://manecha.github.io/task_1/

## 作った理由
既製のタスク管理アプリは、使いにくい点や、ほしい機能がなかったりしたため、自分用に作りました。開発の練習も目的としています。

## 機能
- 日付ごとのタスク一覧（前後の日への移動）
- タスクの追加・編集・削除・完了チェック
- ドラッグでの並び替え
- カテゴリの登録、色分け、カテゴリでの絞り込み
- タスクの日付変更（「明日へ回す」）
- データのファイル保存・読み込み（バックアップ）

## 使い方
iPhoneのSafariで上のURLを開き、「ホーム画面に追加」するとアプリのように使えます。

## 使用技術
- HTML / CSS / JavaScript（1ファイル、フレームワークなし）
- データ保存: ブラウザのlocalStorage
- 公開: GitHub Pages
- 開発: VSCode, Git, GitHub
